# Frontend Onboarding Milestone

A foundational project created to verify the local development environment, tooling, and version control workflow.

## Project Structure
- `index.html`: Semantic layout and milestone status.
- `style.css`: Responsive design using CSS custom properties and Flexbox/Grid.
- `script.js`: Interactive DOM manipulation, live system clock, and theme toggling.

## How to Run
Open `index.html` directly in any web browser, or launch it with the VS Code Live Server extension.
